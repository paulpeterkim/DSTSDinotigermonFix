# Dinotigermon — Ground Fang / Highland Fang

[Download the mod ZIP](https://github.com/paulpeterkim/DSTSDinotigermonFix/raw/refs/heads/main/downloads/Dinotigermon_Fang_Skills_TEST.zip)

This test build edits the uploaded Dinotigermon v1.11.0 mod by dacare. It includes
new Ground Fang and Highland Fang attacker animations, cameras, and the requested
skill names and descriptions. The ZIP includes detailed installation notes.

Install it in place of the original Dinotigermon mod; do not enable both copies.
Keep the existing Reloaded-II/DSTS.ModLoader dependencies installed.

The files passed Blender, animation-format, typed-data, and archive integrity
checks. They have not been tested in the game. Synchronized victim pinning and
cutting effects are not implemented; the animations control Dinotigermon only.
Ground Fang targets one enemy; Highland Fang targets all enemies. Both use the
supplied second skill's basic balance (physical Null, power 55, SP 300, one hit).

Checksums are in [downloads/SHA256SUMS.txt](downloads/SHA256SUMS.txt).
